版式B v47 · 设计说明(仅开发者视图 ?dev=1 可见)
  • 对话呈现 · 分边规则:课文台词是左右分边气泡。本书主角是盼盼,只有盼盼的话放右侧,其余角色一律左侧——朵朵、爸爸、妈妈,以及后面各课出现的飞飞、阿虎、乐乐、老师都在左。这样孩子一眼认得出哪句是主角说的,也贴合聊天界面「自己在右」的习惯。换主角或加角色只改 HERO 一行。说话人只用头像圆表示,姓名收进头像 title 与整行 aria-label;主角那侧的气泡用强调色的浅调,不用强调色本身——强调色在本页是「可点击」的语义。气泡本身就是朗读按钮,不另挂喇叭。
  • 版心与行长:容器放宽到 1160,但纯文本另设行长上限(--measure 34em):卡片、图池、字格阵吃满宽度,句子不跟着变长。
  • 中文排版:正文块开启 line-break:strict 走 CJK 避头尾规则。逐字注音会把每个字裹成独立的行内块、绕过浏览器内建的断行规则,所以另外把「标点 + 它前一个字」焊成不可断的单元,句号逗号问号不会被挤到行首。依据是 GB/T 15834 与 W3C CLReq。
  • 用词与界面语言:站名与板块名换成孩子看得懂的说法(今天要学什么 / 故事一 / 认字 / 写字 / 跟盼盼学说法 / 读一段),教研代号(循环、评估流、题型编号)只留在开发者视图。界面语言选定后只出该语言,不再叠一行中文。行程单每条是「序号 + 名称」,顶栏站选择器按最长的一条把宽度定死(照真实结构量,序号是定宽块不是空格),换站时前后箭头不会左右跳;顶栏按钮统一 38px 高,纯图标的一律 38×38。
  • 换节的三条路径:顶栏箭头与行程单管跳转,底部大按钮管顺读;此外触屏可左右滑,内容跟着手指走、松手超过 70px 才翻页、不够就弹回,已经到头的方向阻尼加重(手感上告诉你没有下一节了);方向在第一次移动时锁定,纵滑一律让给页面滚动;田字格、听写面板、翻牌区内不响应,桌面把鼠标移到左右边缘会浮现半透明箭头(只在有 hover 的设备出现)。
  • 底部续读:每一站末尾给一个「下一站 · X」的大按钮,读完直接往下走,不必回到顶栏找箭头;末站换成「这一课学完了」。全课连读模式下不出现。设计说明只在开发者视图(?dev=1)可见。
  • 小考场:听力 6 题正式入场——听1 判断题配图判对错,听2 对话选图,音轨未备期用朗读代播;顶部序号点去掉,改为每题左侧圆形题号 1—10;作答期间只标记选择不判对错,答满十题才能「交卷」,交卷后一次性给分,错题给「再试一次」并退回未交卷状态。
  • 设置菜单:顶栏常驻五件——回课程列表、题名、行程单、上一/下一、右侧三横线。三横线点开只装阅读偏好:语言、正文字号、拼音、译文、朗读速度、阅读方式、主题。账户体系属于外层的书架与课程列表页,不放进课内页。教师层、学习记录、制作清单是开发期工具,不做界面切换,网址后加 ?dev=1 才出现。
  • 界面语言:接正式版 engine 的 I18N 结构,支持中文 / English / Bahasa Indonesia,只译界面不碰课程内容,切换时同步改 html lang。
  • 夜间模式:只换中性色与卡面,角色配色与橙色强调保持不变,笔顺格、翻牌背、占位框都各自配了夜间底色。
  • 可访问性:拼音层对辅助技术隐藏、整句用 aria-label 提供(否则读屏会念成「zhè这ge个」);字格阵与牌阵用 roving tabindex,整组只占 Tab 序列一格、组内方向键移动;翻牌卡补了 role 与键盘操作;英文译文、次要文字、橙色主色、牌背问号四处改到 WCAG AA 达标。
  • 答题可重做、进度不丢:小考场与循环练的作答状态存在 DOM 之外,切站重渲染后按状态回填;答错的题给「再试一次」,重做与首答分别记事件。
  • 朗读可暂停:整段朗读支持暂停与从当前句继续,不必从头重放。
  • 学习记录:事件结构对齐正式版 platform.js 的 PP.logEvent(进入站点、点读台词、播放动画、查看汉字、笔顺测验、作答与重做、翻牌通关、改设置),顶栏徽标实时计数,面板可查看与导出;接平台时把内存队列换成 PP.logEvent 即可。
  • 顶栏合一:题名、行程单入口、功能按钮压进同一行藏蓝栏。配色、字体、按钮圆角与强调色全部沿用版式B自己的体系——藏蓝主导、橙只做交互强调,与原左栏行程单同源。
  • 行程单入口:常态只显示当前站(橙色站号 + 圆体站名 + 计数);点开后垂直单列列出全部 11 站,每站带副题,走过的站号变绿并打勾,底部是行程进度条。再点收起,点空白或按 Esc 亦收起。
  • 按钮:沿用正式版顶栏的按钮集合与语义——书架、上一/下一、译、朗读速度、拼音、单双、制作清单;「页」改为「站」,页码并入行程单入口。
  • 单站 / 全课:沿用原版单页/双页的语义位。单站为一屏一站;全课为整课连读长卷,顶栏站名随滚动自动跟随。
  • 拼音:与 build.py 同一注音管线(pypinyin + OVERRIDE 多音字表)在构建期生成注音表,逐字上标。本课多音字依正本《注音提示》:过 guo(轻声)、起来 qǐlái(保持全调)、快要 kuàiyào。
  • 译 / 教师分层:「译」只管英文对照(目标、例句、课文四、发现);「师」管场景说明、注音提示与听力文本。学生视图默认两者全关,零拼音零元语言。
  • 字号统一与调节:正文字号按内容分类归口成一套 CSS 变量——课文正文、句子、词语、展示词、单字、大字六级楷体内容,加标题/界面正文/次要/注解/拼音五级界面文字,同类内容全书同号。顶栏「A」按钮点开是一张三选一的小菜单(小 1.15 / 普通 1.32 / 大 1.50,默认普通,每项左侧有对应字号的「字」做预览),整个内容区连同行距、字格、头像、姓名列一起等比放大;顶栏、行程单与制作清单保持原尺寸,操作区不跟着晃。
  • 记忆翻牌:认一认字格阵下方接正式版生词页的翻牌玩法——先摊开看牌听音,点「开始翻牌」洗牌扣起并计时,牌面同正式版:一面是拼音在上、中文词在下,另一面是英文释义。玩法分两关,两个入口一开始就并排给出、可直接任选:第一关洗牌但不翻面,牌全摊着点成对,先把词与英文的对应关系练熟(配错抖一下红边,不罚);第二关把牌全扣过来,凭记忆配对,配错翻回。过了第一关的结算面板也留了直通第二关的按钮。两关分别计时、分别记最快成绩,通过第二关放彩纸。列数按可用宽度自适应(4→3→2)且避开末行落单,牌面随正文字号一起缩放。
  • 笔顺字库:本课 18 字笔顺全部入库(一级库 7 字 + 二级新字 11 字,取自 hanzi-writer-data v2.0.1)。该数据衍生自 Arphic 字体,依 ARPHIC PUBLIC LICENSE 分发:可免费商用,但须随产品附上未经改动的 ARPHICPL.TXT。
  • 汉字时间:认一认与写一写照正式版「汉字时间」页重做——大格 HanziWriter 笔顺演示、字/拼音/例词信息板、字格阵(要写的字右上角标「写」);写一写另有两个全屏面板:「练一练」给淡色轮廓、错两次亮下一笔,「听写」只报读音与例词、凭记忆手写,写完给成绩。hanzi-writer.js 与本课笔顺数据已内嵌,离线可用。
  • 插画与动画位:沿用正式版 .art 机制——封面、三篇课文、课文四、读1 图池 ×4、听2 选项 ×4、听1 题图 ×3、文化图,加台词行的四个角色头像位,共 21 个位。有图显图,无图显制作说明(文件名、建议尺寸、画面说明);三张课文图带 data-story,点图即随朗读逐行播放,与台词行高亮同步。
  • 制作清单:插图位与音轨位由本课数据现场装配,画面说明含《人物规范》v5 画风串与 SY02 身份锚点造型串,朗读文本逐字取自正本,可一键复制;另列「待补数据」一节。
